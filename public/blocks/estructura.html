Estructura de AntCMS

{Code: php} AntCMS ├───config ├───panel ├───public │ ├───blocks // Bloques de contenido │ ├───content // Contenido │ ├───documents // Documentos tipo pdf,docx etc │ ├───fonts // Fuentes │ ├───icons // Iconos │ ├───images // Imagenes │ ├───javascript // Archivos Javascript │ ├───stylesheets // Archivos Css │ └───views // Plantilla frontend ├───src │ ├───Ant // Clase Ant │ └───Vendor // Otras clases └───tmp // Archivos temporales {/Code}
